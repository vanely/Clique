│    │    └─ Enable: Stop                                                      │
│    │                                                                          │

│    ├─> Validate intervals (>= 100ms)                                         │
│    ├─> Update AppState                                                       │
│    ├─> Call SaveSettings() in main.ahk                                       │
│    └─> Show success message                                                  │
│                                                                              │
│  TestClick()                                                                 │
│    ├─> Read coordinates from GUI                                             │
│    ├─> Validate not (0,0)                                                    │
│    ├─> Save current mouse position                                           │

  MODULE: automation.ahk (AUTOMATION LOGIC)
════════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────────┐
│                        COORDINATE CAPTURE FLOW                               │
│                                                                              │
│  [User presses F3 or clicks Capture button]                                 │
│             │                                                                │
│             ▼                                                                │
│  StartCoordinateCapture()                                                    │
│    │                                                                          │
│    ├─> Check if automation running ───> [NO]  ─┐                             │
│    │                                            │                             │
│    │                                   [YES]    │                             │
│    │                                     │      │                             │
│    │                                     ▼      │                             │
│    │                              Show error    │                             │
│    │                                  return    │                             │
│    │                                            │                             │
│    │                              ◄─────────────┘                             │
│    │                                                                          │
│    ├─> Set AppState.isCapturing = true                                       │
│    ├─> Show tooltip: "Click anywhere to capture"                             │
│    ├─> KeyWait("LButton", "D")  ──> [WAIT FOR CLICK]                         │
│    ├─> MouseGetPos(&x, &y)                                                   │
│    ├─> Update AppState.targetX/Y                                             │
│    ├─> Update GUI fields (xCoordEdit, yCoordEdit)                            │
│    ├─> Set AppState.isCapturing = false                                      │
│    ├─> FlashLocation(x, y)  ──> Green pulsing indicator                      │
│    └─> UpdateStatus("Coordinate captured")                                   │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│                       AUTOMATION EXECUTION FLOW                              │
│                                                                              │
│  [User presses F1 or clicks Start button]                                   │
│             │                                                                │
│             ▼                                                                │
│  StartAutomation()                                                           │
│    │                                                                          │
│    ├─> Validate coordinates not (0,0) ───> [FAIL] ─> Show error, return     │
│    ├─> Read intervals from GUI                                               │
│    ├─> Validate intervals >= 100ms ──────> [FAIL] ─> Show error, return     │
│    ├─> Set AppState.isRunning = true                                         │
│    ├─> Reset AppState.currentTimer = 1                                       │
│    ├─> UpdateGUIState(true)  ──> Disable controls                            │
│    ├─> UpdateStatus("RUNNING...")                                            │
│    └─> PerformClick() ──────────────────┐                                    │
│                                         │                                    │
│  ┌──────────────────────────────────────┘                                    │
│  │                                                                            │
│  ▼                                                                            │
│  PerformClick()   ◄─────────────┐                                            │
│    │                             │                                            │
│    ├─> Check AppState.isRunning ┼──> [FALSE] ─> return                       │
│    │                             │                                            │
│    │                    [TRUE]   │                                            │
│    │                             │                                            │
│    ├─> Click(AppState.targetX, AppState.targetY)                             │
│    ├─> ShowClickFeedback(x, y)  ──> Yellow pulse indicator                   │
│    │                                                                          │
│    ├─> Determine next interval:                                              │
│    │     │                                                                    │
│    │     ├─ If currentTimer = 1:                                              │
│    │     │    ├─ nextInterval = interval1                                     │
│    │     │    └─ currentTimer = 2                                             │
│    │     │                                                                    │
│    │     └─ If currentTimer = 2:                                              │
│    │          ├─ nextInterval = interval2                                     │
│    │          └─ currentTimer = 1                                             │
│    │                                                                          │
│    ├─> UpdateStatus("Next click in X ms")                                    │
│    └─> SetTimer(PerformClick, -nextInterval) ──┘ [SCHEDULE NEXT CLICK]       │
│                                                                              │
│  Pattern: Click → Wait(interval1) → Click → Wait(interval2) → Repeat...     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│                          STOP & EMERGENCY FLOWS                              │
│                                                                              │
│  StopAutomation()  [F2 or Stop Button]                                      │
│    ├─> SetTimer(PerformClick, 0)  ──> Cancel scheduled click                 │
│    ├─> Set AppState.isRunning = false                                        │
│    ├─> Reset AppState.currentTimer = 1                                       │
│    ├─> UpdateGUIState(false)  ──> Re-enable controls                         │
│    └─> UpdateStatus("Stopped")                                               │
│                                                                              │
│  EmergencyStop()  [ESC key - works anytime]                                 │
│    ├─> Check if AppState.isRunning                                           │
│    ├─> Call StopAutomation()                                                 │
│    ├─> Show "EMERGENCY STOP" tooltip                                         │
│    └─> Auto-hide tooltip after 2 seconds                                     │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│                          VISUAL FEEDBACK SYSTEM                              │
│                                                                              │
│  FlashLocation(x, y)  [Green flash at captured location]                    │
│    ├─> Create temporary GUI overlay                                          │
│    ├─> Position at (x-10, y-10) with size 20x20                              │
│    ├─> Flash 3 times (show/hide cycle)                                       │
│    └─> Destroy overlay                                                       │
│                                                                              │
│  ShowClickFeedback(x, y)  [Yellow pulse at click location]                  │
│    ├─> Create temporary GUI overlay                                          │
│    ├─> Position at (x-5, y-5) with size 10x10                                │
│    ├─> Show for 100ms                                                        │
│    └─> Auto-destroy                                                          │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  TIMER & SCHEDULING ARCHITECTURE
════════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────────┐
│                      TIMER-BASED EXECUTION MODEL                             │
│                                                                              │
│  AutoHotkey SetTimer() is used for:                                          │
│                                                                              │
│  1. Automated Clicking Loop                                                  │
│     SetTimer(PerformClick, -interval)  [One-shot timer]                      │
│     │                                                                         │
│     └─> Executes PerformClick() after interval                               │
│         ├─> Performs click                                                   │
│         ├─> Shows feedback                                                   │
│         └─> Schedules next click with SetTimer(PerformClick, -nextInterval)  │
│                                                                              │
│  2. Tooltip Auto-Hide                                                        │
│     SetTimer(() => ToolTip(), -5000)  [Hide welcome after 5s]                │
│     SetTimer(() => ToolTip(), -2000)  [Hide emergency stop after 2s]         │
│                                                                              │
│  3. Visual Feedback Auto-Cleanup                                             │
│     SetTimer(() => pulse.Destroy(), -100)  [Remove click pulse after 100ms]  │
│                                                                              │
│  4. Status Message Auto-Clear                                                │
│     SetTimer(() => statusText.Value := "Ready", -duration)                   │
│                                                                              │
│  Note: Negative interval = one-shot timer (executes once then stops)         │
│        Positive interval = repeating timer (not used in this app)            │
│        Zero interval = cancels timer                                         │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  KEY ARCHITECTURAL PATTERNS
════════════════════════════════════════════════════════════════════════════════

1. SEPARATION OF CONCERNS
   • main.ahk:      Bootstrap, state, settings I/O, hotkey registration
   • gui.ahk:       All UI components, user interactions, visual updates
   • automation.ahk: Click logic, coordinate capture, timer management
   • utils.ahk:     Pure helper functions, no dependencies

2. CENTRALIZED STATE
   • Single AppState object holds all runtime state
   • All modules read/write to AppState
   • Prevents state synchronization issues

3. EVENT-DRIVEN ARCHITECTURE
   • Hotkeys trigger functions (F1 → StartAutomation)
   • GUI buttons trigger functions (OnEvent "Click")
   • Timers schedule deferred execution
   • No polling loops

4. VALIDATION AT BOUNDARIES
   • User input validated before use
   • Coordinates checked before clicking
   • Intervals validated before automation starts
   • State checked before state changes

5. VISUAL FEEDBACK SYSTEM
   • Every action has visual confirmation
   • Temporary overlays show click locations
   • Status text always reflects current state
   • GUI controls disabled/enabled based on state

6. FAIL-SAFE MECHANISMS
   • Emergency stop (ESC) always available
   • GUI lockout prevents conflicts during automation
   • Minimum interval enforced (100ms)
   • Early returns on invalid state

7. MODULAR, TESTABLE DESIGN
   • Each function has single responsibility
   • Clear function names indicate purpose
   • No tight coupling between modules
   • Easy to add new features or modify existing ones
